# Defender II 图片参考库

采集日期：2026-09-01  
目标产品：DroidHen《Defender II》（Android 包名 `com.droidhen.defender2`）

本目录依据 `docs/defender-ii-software-architecture.md` 与 `docs/defender-ii-requirements.md` 整理，服务于兼容重制/同类实现的视觉研究。图片按来源可信度和年代分组；逐图原始链接见 [来源清单.csv](来源清单.csv)。

## 目录

- `01_官方`：DroidHen 官网横幅、Google Play 与 Apple App Store 当前商店截图。适合确认当前官方构图、色彩、HUD 和技能表现。
- `02_社区论坛`：TapTap 玩家帖子截图。用于观察真实玩家档案、高阶段状态和长期游玩情境。
- `03_玩家与评测`：2012 年同期玩家/媒体实机截图。适合核对经典版本的主菜单、研究树、Battle、商店、Honors、结算和战斗 HUD。

## 版本与使用注意

- 官方商店图反映 2026-09-01 可见的当前页面；2012 年评测图更接近需求文档中的 `classic-2012` 规则和旧版 UI。两者不能混作同一版本的精确证据。
- Google Play 与 App Store 的同场景图片保留为平台裁切/压缩对照，不是重复遗漏。
- 社区和玩家图片只能作为 B/C/D 级辅助证据；数值、等级上限、奖励和商店价格仍需实机或多来源验证。
- 图片版权归原作者、DroidHen 或相应平台所有，仅作为内部视觉研究参考。不要直接打包进游戏、对外发布或用于商业宣传；正式生产应使用原创或已获授权资产。
