# 火、冰、雷：单发落击、区域倾泻与全屏倾泻

日期：2026-09-08。当前适用：config v10 / `aegis-windows-dense-barrage-v1`（同步回退规则）。这是源码实现说明，不代表现有 EXE 已重新发布。

历史变更：config v7 引入单发落击/区域倾泻/全屏倾泻；v9 开放九个技能节点的持续伤害研究，范围和状态持续时间在节点研究 20 级封顶。v10 缩短三阶投放窗口、增加颗数，并改用分散落点；蓝耗、冷却、每颗伤害、前置与研究价格保持。超出旧研究上限后的规则见 [无尽研究说明](endless-research.md)。

## 1. 依据与变更范围

参考库中的 `参考/03_玩家与评测/it-blog_03_魔法研究树.png`、`unwire_05_魔法研究树.jpg` 用于三级分支与研究布局；`参考/01_官方/` 下的火、冰、雷技能截图用于元素表现定位。参考截图不作为正式游戏资源打包。

本次以用户提出的“单发从天落下 → 指定区域随机倾泻 → 全屏随机倾泻”为行为依据，替换旧版固定圆心、等间隔的多轮结算。三系共享同一落击机制，火系灼烧、冰系冻结与减速、雷系眩晕与打断。X/Y/Z 未指定，下面是可调的项目初始平衡值，**不是原版实测数据**。不更改此前研究依赖、解锁价格、装备规则、城墙或地面素材。

## 2. 投放规则

| 阶位 | 投放方式 | 升级是否改变投放方式 |
|---|---|---|
| I | 一颗从屏幕上方飞到指定位置，到达后才结算 | 否 |
| II | 指定点为圆心，在半径 X 内随机选取 Z 个落点；Y 秒内按随机、不重叠、不等间隔的时刻发射 | 否；X/Y/Z 固定 |
| III | 忽略施法坐标，在整个战场分散选取 Z 个落点；Y 秒内随机发射，保留少量随机空隙 | 否；Y/Z 固定，空隙避让使用实际溅射半径 |

- 发射窗口单位是模拟 tick，30 tick = 1 秒。首发在施法当 tick 发出，其余发射时刻从窗口内不放回抽样；也排除恰好等间隔的随机结果。
- **Y 指发射窗口，不是最后一颗的落地截止时间**。火球/冰晶飞行 0.6 秒；雷击下传约 0.33 秒。因此末次命中可能晚于施法后 Y 秒。
- 二阶落点在“圆盘与战场交集”内抽样，不把越界点硬夹到边缘，避免沿边缘排成直线。三阶覆盖逻辑战场 `castle_x_milli..width_milli × 0..height_milli`，不覆盖城内区域；不保证每名敌人都被击中。
- 三阶在 24×16 抖动候选格中逐次选取距离已有落点最远的点，再随机打乱投放顺序，减少扎堆与大片漏区。每次施法在战场中部随机保留一个小开口（半径约为战场短边的 9.5%），落点距开口中心至少为“实际溅射半径 + 开口半径”。因此满范围研究也不会把一轮倾泻变成全场必中的判定；不是额外伤害屏蔽区，仍只按普通圆形伤害结算。开口随每次随机流变化，多次/多系列施法不共用固定安全区。极端自定义配置若让单发半径大于整个战场、无法保留几何开口，则降级为普通随机落点，避免空候选崩溃。
- 每一颗都在自己的落地 tick，按**当时敌人位置**独立判定；可以落空，可以重复命中同一存活敌人。雷系不再限制为若干个最近目标。
- 全部落点与时间由独立的种子随机流产生，普通弓箭或刷怪的随机消耗不会改变倾泻图案；同种子、同命令可以重复验证。

## 3. 单次命中与元素后效

设敌人中心到落点的距离为 d，直击半径为 r，溅射外半径为 R，直击伤害为 D，溅射峰值为 S：

```text
d <= r       ：D
r < d < R    ：floor(S × (R - d) / (R - r))
d >= R       ：0
```

直击区不是“直击再加一次溅射”，每颗对每个敌人只结算一次。命中依据敌人中心；最终伤害继续经过已有护甲/元素抗性。向下取整导致溅射最外侧可能提前降到 0；零伤害点不附加状态。

- **火**：有伤害且存活的目标灼烧，每 0.5 秒扣血。重复命中刷新持续时间、保留更强的灼烧伤害，不无限叠加多个灼烧实例，也不推迟已有的下一次灼烧 tick。灼烧本身仍经过伤害/状态抗性。
- **冰**：有伤害且存活的目标冻结，不能移动或攻击；解冻后按配置速度比例减速。减速剩余时长在冻结期间不消耗；重复命中保留较强减速和较长控制时间。
- **雷**：有伤害且存活的目标眩晕，推迟普通攻击，并重置首领特殊技能蓄力。首领状态抗性仍生效。
- 外圈衰减作用于即时溅射伤害；灼烧强度/控制时间使用该颗技能的参数，再经过目标抗性，不额外按距离缩短。

## 5. 研究、参数与装备

```text
                炽焰火球 Lv.3 → 陨石术 Lv.3 → 末日审判
魔力研究 Lv.1 → 冰川尖刺 Lv.3 → 冰霜新星 Lv.3 → 冰河时代
                雷霆打击 Lv.3 → 雷暴 Lv.3 → 诸神黄昏
```

每个技能独立研究，最高 Lv.8。基础技能初始可用：一级研究即增加一次属性；高级技能 Lv.1 是解锁，其后每级增加一次属性。

| 每次研究增量 | I | II | III |
|---|---:|---:|---:|
| 火直击伤害 | +9 | +14 | +20 |
| 冰直击伤害 | +8 | +14 | +20 |
| 雷直击伤害 | +11 | +14 | +20 |
| 溅射峰值（三系） | +5 | +8 | +11 |
| 直击半径（三系） | +4 | +4 | +4 |
| 溅射外半径（三系） | +6 | +6 | +6 |

火系每级另加灼烧伤害 2、持续时间 0.2 秒；冰系每级另加冻结 0.1 秒、减速持续时间 0.2 秒、减速强度 1 个百分点（速度最低为原速的 10%）；雷系每级另加眩晕 2 tick，约 0.067 秒。

- 技能研究不增加 Mana、颗数、发射窗口、投放半径或飞行时间。通用范围研究增强单颗直击/溅射半径，独立冷却研究仍减少冷却；元素荣誉增强该元素的直击、溅射及火系灼烧伤害。
- 修改初始值的位置：`content/config/game_rules.json` 的 `skills`；同时同步 `game_rules_fallback.json`。投放字段为 `target_mode/impact_count/barrage_duration_ticks/area_radius_milli/fall_ticks`；单颗属性与其 `*_per_level` 字段独立配置。
- 校验器检查三个连续阶位、递增 Mana/伤害/直击半径、合法研究前置、R > r、S <= D（含满级），并拒绝按研究等级增加投放参数。单次最多 64 颗、窗口最多 600 tick、飞行最多 90 tick，避免配置失误导致无界调度。
- 研究详情“当前／下级”并排显示：直击、溅射、投放、元素后效，三条技能主链同屏可见。HUD 和主界面技能提示使用同一有效属性查询。
- 原三元素槽、低阶重装备、首次解锁自动装备、继续升级不覆盖当前装备，以及保存失败回滚规则保留。基础研究 ID 不变，旧档等级与装备不丢失。
- 每次施法只付一次 Mana、累计一次施法数；同元素共享冷却。未解锁、未装备、冷却中或 Mana 不足均不创建投放队列、不消耗技能随机数。一/二阶拒绝越界目标；三阶忽略坐标，但在 UI 上松手仍是取消操作。

## 6. 核心与表现边界

```text
cast_skill 命令
  → 校验、扣费一次 → skill_cast
  → active_spells 保存所有 launch_tick / impact_tick / 落点与有效属性
  → 发射 tick：skill_launch；falling_spells 只读快照提供在途轨迹
  → 落地 tick：独立直击/溅射/状态结算 → skill_pulse
  → 表现层绘制爆炸/冰晶/电弧并播放落地音效
```

`SkillCatalog` 提供研究、HUD、核心共用的有效属性；`SkillSystem` 调度与命中；`RunModel` 持有专用 `_spell_rng` 与队列。先执行当前 tick 的技能落击，再更新敌人的状态与移动；因此落击附带控制可以阻止当 tick 的行动。

表现层仅使用快照插值下落位置，不能因帧率或动画结束提前造成伤害。每个 `skill_pulse` 只绘制一次真实落点的爆炸/冰击/主雷柱；雷击到敌人的短电弧只表现溅射，不额外制造多根落雷。暂停冻结动画与模拟，结束关卡清空队列。

Profile schema 仍为 v6，不修改存档结构。当前 config v10 与新 `ruleset_version` 区分旧版事件流；旧回放不能作为新规则下的逐事件一致性基准。

## 8. v10 鼠标、主页装备与密度验收

- 未选中技能时显示十字准星；按 1/2/3 或点击 HUD 技能按钮后，三阶也立即显示相应火焰/雪花/闪电魔法光标及阶位。无效施法加红色不可用标记；成功施法/取消后恢复准星，失败保留选择。光标与范围预览不参与屏幕震动；移入 UI、暂停、窗口失焦/移出和离开战斗时恢复系统指针。
- 主页三系槽位均使用 MenuButton：列出本系 I/II/III、名称、蓝耗和当前装备；已解锁项即时保存，未解锁项跳到对应魔法研究节点。与研究页共用 `GameApp.select_skill` 和 `equipped_skills`，失败不改变装备，成功同步当前研究详情和下一场战斗。
- `tests/skill_interaction_acceptance.gd`：覆盖三系 × 研究 1/20/200 级 × 12 种子，以 58×37 网格抽样真实伤害圆盘并含边界。**一轮累计伤害范围覆盖率 95.8%–97.7%**，不是同一帧画面覆盖率，也不保证杀死相同比例敌人；满范围研究保留空隙。三个系列同时施放的 168 发均发射并结算，100 敌人下规划约 8.5 ms、运行 tick p95 约 2.2 ms（本机测量，非所有硬件保证）。
- 专项无头 234 项、真实渲染 261 项通过；渲染额外验证隐藏系统箭头和双语三档 UI 缩放下的下拉定位。截图位于被忽略的 `Builds/skill-interaction-review/`；正式导出门禁新增该专项。历史 v7 验收结果保留在上一节，当前回归记录见 [实现状态](implementation-status.md)。
