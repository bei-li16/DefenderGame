# 城墙与弩机风格整理

2026-09-23，接续 [整机 UI 重制](production-ui.md)。本页保留第一次整理的历史记录；用户随后指出斜墙、风格、墙段错位和外侧延伸问题，现行实现与验证请见 [城墙四项规则修正](straight-wall-art.md)。以下旧城墙布局与锚点已被替代。

## 问题与处理

上一版城墙使用密集小砖、扶壁、铆钉及酒红旗帜，弩机采用写实金属与齿轮，和原有蓝银色城防、卡通怪物不一致。旋转整张弩机图片会把底座一起转走，后坐的非等比缩放又会改变弓臂形状。

- 恢复 `Gamematerials/主城墙new.png` 的完整双塔连墙：大块蓝灰石材、规则垛口、蓝旗、银色包边和青蓝水晶。不复制塔楼、不拼接墙面、不拉伸建筑。
- 复用同套 `Gamematerials/弩塔.png`，在 Godot 中以缓存网格和源图 UV 分离弩身及固定底座，排除原弩塔的圆形城台和多余铰链。源 PNG 不改写。
- 固定底座落在中央平台，仅上部弩身绕射击轴转动；后坐为沿轴 6 像素的刚性位移，取消原先的横缩纵拉。原素材自带待发箭，不再额外叠加第二支箭。
- 塔顶直接使用原画水晶，取消额外绘制的水晶冠和圆环；魔法塔升级后只在晶体内部局部发光。同步调整放电起点及墙面受击轮廓。
- 弩塔导入上限从 512 提升到 1024，保留 mipmap，改善倾斜时细弦和金属轮廓的清晰度。

城墙等比缩放 0.55，源图平台中心 `(635,733)` 对应世界 `(245,587)`。弩机源图尺寸 `1448×1086`，缩放 0.18，射击轴锚点 `(650,294)` 对应核心发射原点 `(245,555)`。战斗坐标、伤害、存档与规则不变。源弩机为二维绘制素材，本轮仍采用二维瞄准旋转。

曾使用内置 imagegen 尝试生成简化城墙和独立弩身；检查实际文件发现生成背景为 RGB 棋盘格，未满足真实透明通道要求，因此全部弃用，未引入任何生成 PNG。提示词与失败记录保存在本地 `Builds/fortress-refinement-review/image-generation-attempts.md`。本轮最终素材路径为上述两张原始 PNG。

## 实际视觉验证

使用 Godot 4.7.2 Compatibility / GTX 1060 的实际游戏场景渲染，并打开截图检查。专项覆盖普通/熔岩地面、1920×1080 / 1280×720、水平 / 向上 55° / 向下 55° / 向上 25° 后坐，共 16 张全景和 16 张弩机局部截图。检查了平台接合、弓臂比例、弦的裁切、城墙轮廓与 HUD 遮挡；另检查魔法塔放电、墙面受击及 Boss 战场。

截图中的敌人位置和姿态为固定验证布置，不是连续试玩录像。测试通过 `--script` 使用隔离存档。
