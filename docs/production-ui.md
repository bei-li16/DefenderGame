# 城墙、弩机与整机 UI 重制

2026-09-23，源码 1.7 / config12 / schema6。此增量替代上一轮城墙与弩机视觉方案；不代表新 EXE 已发布。

## 检查与修改

| 原问题 | 本轮处理 |
|---|---|
| 城墙、弩机投影与体量不一致 | 新生成完整双塔连墙与独立机械弩机，按源图安装环和旋转足定位，取消旧弩座重复绘制 |
| 左下大面板遮住近端塔楼 | 状态区改为城墙右下侧的紧凑血量/法力/装备信息；两座塔楼保留完整轮廓 |
| 默认圆角面板、默认进度条、系统表情 | 统一生成石材/铁框/少量黄铜的九宫格皮肤及 16 个绘制图标，主操作使用酒红珐琅面 |
| 首页背景被大面板遮住 | 标题与导航直接置于原背景，右侧局部暗化提高文字对比；保留关卡摘要、Boss 预警和全部导航 |
| 战斗顶栏宽重、信息混杂 | 左侧暂停与关卡，中间波次/部署进度，右侧金币；Boss 与告警分层，不拦截战场输入 |
| 满血填充遮住边框 | HUD 计量条独立绘制金属外框、内槽填充和图集端帽；0/1/50/100% 使用相同内部量程 |
| 研究节点价格与等级挤在边上 | 图标、名称、等级与价格分区；统一全宽研究工作区，详情改为无嵌套边框的底部信息带 |
| 设置布局过散、滑杆无数值 | 音频/操作与显示分为两列，滑杆显示百分比；保留管理员入口但默认折叠 |
| 调音量导致最大化窗口恢复 | 只有分辨率、全屏和无边框变更才重新应用窗口几何，其他设置保留当前窗口状态 |
| 荣誉与存档纵向浪费空间 | 荣誉双列，三存档并排，长说明自动换行；原保存、切换和失败语义不变 |
| 结算靠空格对齐数据 | 图标/指标/数值三列布局，暂停、教学、快捷设置和确认框使用同源主题 |

保留现有战斗规则、伤害、技能随机落点、研究与奖励参数、存档格式、原素材文件和内院不透明遮挡。普通/熔岩地面继续使用完整配对图片，渲染色调转为较中性的灰绿石材。既有九技能图集、敌人主体、特效及音频不在本轮重新生成。

`UiAssets` 以归一化区域缓存纹理切片；`DefenderUiTheme` 统一按钮所有状态、弹出菜单、输入框、滑杆、滚动条、开关、分隔线和提示框。九宫格只拉伸中段，按钮各状态内边距相同。`hud_meter.gd` 缓存外框、填充纹理和端帽，不在每帧分配新资源。所有新 PNG 通过 Godot 导入资源映射加载，不在运行时读原图路径。

所有脚本共享自动化隔离存档，必须串行运行。

```powershell

& $GodotConsole --path . --script tests/production_ui_acceptance.gd -- --capture
& $GodotConsole --headless --path . --script tests/resolution_layout.gd
& $GodotConsole --path . --script tests/window_mode_acceptance.gd
& $GodotConsole --path . --script tests/fortress_art_acceptance.gd -- --interactive
```

截图使用实际 Godot 渲染器及菜单/战斗场景，但战斗布阵、半血和结算是专项注入的可复查状态，不是同一场连续战斗录像。原生鼠标键盘试玩另行进行。

真实鼠标键盘试玩使用隔离第 30 关：检查下拉位置、音量滑杆、技能选择/落点、蓝耗/冷却、暂停。试玩发现音量更新重置窗口的问题已加入窗口专项回归。正式玩家进度未使用，试玩窗口已关闭。
