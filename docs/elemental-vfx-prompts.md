# 三系特效生成提示词

## 三系技能透明特效图集（2026-09-22）

使用内置 imagegen，以本地官方/玩家截图的表现特征作为设计参考；新建原创图集，未裁切原游戏画面，未改动既有 PNG。最终输出为 `Gamematerials/VFX/fire-atlas-v1.png`、`ice-atlas-v1.png`、`lightning-atlas-v1.png`。

下面保存实际使用的完整提示词。要求画布为 1024×1024，但生成结果实际为 1254×1254 RGBA；运行时由 Godot 导入到 1024×1024、启用 mipmap。每张图按 2×2 四格读取，原图保持不变。透明通道和四格独立性由 `elemental_vfx_acceptance.gd` 验证，最终动画/音效设计见 [三系视听重制](elemental-vfx.md)。
