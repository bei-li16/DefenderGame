## 表现流程与边界

`SpellVisuals` 是独立表现模块，复用 `GameArt` 的缓存 AtlasTexture / ArrayMesh，不为碎片逐个建立 Node。替换原来技能命中的圆环、三角形及单条折线，但保留瞄准准星、技能预览及其他系统需要的线条图形。

- 火：落下的熔亮火球与烟焰拖尾 → 快速膨胀爆燃 → 飞散小火舌 → 地面焦痕/余烬与淡出烟气。命中层短暂旋转错相，避免整屏完全一致的印章感。灼烧火舌跟随真实受影响的怪物。
- 冰：带内部明暗和折射面的长冰锥 → 快速生长的晶簇 → 外散碎冰与低位霜尘。冰牢保留透明中心，冻结持续时间来自怪物状态，不能用特效结束时间代替。
- 雷：较暗的分叉先导自空中延伸 → 命中 tick 才绘制白紫主雷击 → 地面枝状电光 → 短余辉。两种雷柱形态交替，眩晕电弧跟随怪物；不在溅射受击者头顶制造额外落雷，也不增加全屏白闪。

火/冰/雷命中表现分别保留约 1.05/1.15/0.55 秒，亮峰快速结束，尾迹渐隐。该时长仅决定美术残留。地面焦痕/霜裂在怪物下方；主体命中在怪物上方；怪物血条和伤害数字在命中特效之上；HUD 仍在独立 CanvasLayer。图集采样有半像素内缩以减少相邻格串色。

I/II/III 共用完整的落击表现，区别继续来自真实单发/区域雨/全屏雨。三阶仍是 3 秒内随机 56/52/60 发，不添加覆盖率、中央空白或视觉补点。落点、fall_ticks、直伤/溅射半径、伤害、魔法消耗、冷却、升级及状态时长均未改。飞行只读取 `falling_spells`，命中只消费 `skill_pulse`，声音只消费真实事件；没有表现层伤害、提前命中或全局 RNG 消耗。

低/中/高画质保留 12/32/64 队列上限，附加碎片数分别 0/2/3。状态特效每只怪最多 4 个贴图片段。所有缓存纹理/网格复用，残留自动过期；暂停冻结动画年龄。完整落击贴图不会因为降低画质退回几何占位。

## 音效与混音

`SoundBank` 启动时一次生成六段 22.05 kHz、16 bit、单声道 PCM，合计小于 220 KB：

- 火：0.38 秒下落风啸，0.88 秒低频爆燃＋滤波轰鸣＋余烬噼啪。
- 冰：0.38 秒高频寒风，0.78 秒碎裂瞬态＋不等频晶体共鸣＋霜粉尾音。
- 雷：0.23 秒充电噪声，0.95 秒电击脆响＋短电弧＋延迟约 0.06 秒的低频闷雷。

使用私有 xorshift 噪声与多层包络，首尾淡入淡出，不消耗战斗随机数。发射由 `skill_launch` 触发，接触由 `skill_pulse` 触发；`skill_cast` 不再重复播放。细微音高变化限制在 0.94–1.06 倍，不影响物理飞行和结算时间。

十个音效播放器分为 4 个命中、2 个发射、2 个武器/界面、2 个告警/结果声部。发射声不会截断命中尾音，Boss 告警不被雨点抢占。命中同元素限流 110 ms，发射 150/150/160 ms；密集时允许声音合并，绝不省略核心结算。保留现有独立音量设置和三套背景配乐。单段 PCM 峰值/端点、分组路由和静音通过自动测试；尚未进行主观听感评分，也未做整机声卡回录的总线削顶测量。
