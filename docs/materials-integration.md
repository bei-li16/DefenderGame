## 动画实现

所有角色源文件都是**单张透明立绘，不是序列帧**。采用表现层共享 `ArrayMesh`：

- 每张图使用 8×8 网格、16 个量化相位；按动作/相位缓存网格，不给每只怪新建动画节点或每帧重建网格。
- 行走根据脚部、翅膀、触手所在 UV 区域变形；实体之间相位错开。30 Hz 快照位置向渲染帧插值，血条跟随显示位置。
- 攻击冷却最后 6 tick 提供蓄力前摇；真正的 `wall_damage` / `boss_special` 事件触发攻击前探和收招。远程光弹是视觉反馈，不会二次扣血或改变核心伤害时机。
- 受击闪色 0.14 秒；死亡保留 0.48 秒的倾倒、缩小、淡出立绘，最多 48 个，过期自动回收。
- 暂停停止战场时钟、后坐、飘字与动作；冻结/眩晕停止角色动作，减速按 `slow_permille` 缩放步频。
- 状态冰晶、灼烧、毒泡和三系列法术保留代码绘制；魔法塔光束、熔岩命中和三种 Boss 特殊技补上对应颜色反馈。

限制：程序变形不能补出单张图片中未画出的肢体背面或完整逐帧挥拳；红龙源图自带火焰和岩石底座，仍保留该立绘姿态。后续若补齐序列帧/骨骼素材，只需替换表现层，不改核心战斗协议。

## 资源与代码

`src/presentation/art/game_art.gd` 是资源注册/UV 裁切入口；`creature_visuals.gd` 消费快照与事件。它们只属于 presentation，不能反向影响 core。

不修改源 PNG。通过 Godot `.png.import` 配置尺寸上限：普通怪、弩塔和箭矢 512；Boss/城墙 1024；武器图标 256；背景 2048，并启用 mipmap。资源使用 Godot 导入映射加载，兼容导出包，不依赖运行时读取原始 PNG 路径。沿用导出配置排除 `参考/`。
